# create-flyonui-vue <a href="https://npmjs.com/package/create-flyonui-vue"><img src="https://badgen.net/npm/v/create-flyonui-vue" alt="npm package"></a> 

The recommended way to start a Vite flyonui-vue project.

### Usage

To create a new Vue project using `create-flyonui-vue`, simply run the following command in your terminal:

```sh
yarn create flyonui-vue
```

The generated template is the same as [create-vue](https://github.com/vuejs/create-vue), with `flyonui-vue` 
already configured under the hood.
